# API-слой работы с базой данных

Текущий backend расположен в директории `api/` и предоставляет CRUD-эндпоинты для таблиц театральной системы.

## Структура `api/`

- `database.py` - подключение к БД и сессии SQLAlchemy
- `models.py` - ORM-модели SQLAlchemy
- `schemas.py` - Pydantic-схемы
- `crud.py` - операции CRUD
- `auth.py` - JWT-аутентификация
- `api.py` - FastAPI-эндпоинты
- `run_api_direct.py` - реэкспорт `app` для совместимости; предпочтительно `uvicorn api.api:app`

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите API:
```bash
python start_api.py
```

## Использование

API предоставляет эндпоинты для всех сущностей в системе:

- `/employees/` - работа с сотрудниками
- `/franchises/` - работа с франчайзингами
- `/theaters/` - работа с театрами
- `/halls/` - работа с залами
- `/scenarios/` - работа со сценариями; см. также `/scenarios/{id}/tz-spec/*` (файл ТЗ, n8n) в [API_DOCS.md](API_DOCS.md)
- `/acts/` - работа с актами
- `/parts/` - работа с частями
- `/shows/` - работа с представлениями
- `/customers/` - работа с клиентами
- `/tickets/` - работа с билетами
- `/votes_common/` - работа с общими голосами
- `/votes_vip/` - работа с VIP-голосами
- `/equipments/` - работа с оборудованием
- `/rents_equipment/` - работа с арендой оборудования
- `/services/` - работа с услугами
- `/rents_service/` - работа с арендой услуг

Для доступа к защищенным маршрутам требуется аутентификация через токен, получаемый по эндпоинту `/token`.

## Безопасность

- Все пароли хешируются с использованием bcrypt
- Аутентификация осуществляется через JWT-токены
- Валидация данных с использованием Pydantic-схем
