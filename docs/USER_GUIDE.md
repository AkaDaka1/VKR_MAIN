# Руководство пользователя (клиент VKR_MAIN)

## Запуск

1. Запустите API (`python start_api.py` или `docker compose up`).
2. Запустите клиент: `python start_app.py`.
3. Войдите под учётной записью сотрудника.

## Основные действия

### Выборка данных

Меню **База данных → Выборка** или соответствующий пункт открывает таблицу сущности (сотрудники, театры, билеты и т.д.). Данные подгружаются в фоне; при повторном открытии в течение короткого времени может использоваться кэш (сообщение в строке состояния).

### Поиск

В верхней панели поле **«Глобальный поиск»** фильтрует **текущую таблицу** по подстроке без учёта регистра.

### Добавление

**База данных → Добавить** или кнопка **«Добавить»** на панели быстрых действий (для активной выборки) открывает форму. Обязательные поля помечены валидацией; для связей с другими таблицами используются выпадающие списки.

После успешного добавления открывается обновлённая выборка по этой сущности.

### Редактирование

Откройте нужную выборку, выделите строку, нажмите **«Редактировать»**. Доступно для: сотрудников, франшиз, театров, залов, показов и билетов.

### Удаление

**База данных → Удалить** или быстрая кнопка **«Удалить»** — выбор записи и подтверждение. Текущий пользователь не может удалить свою учётную запись сотрудника.

### Дашборд

В верхней части окна отображаются агрегированные счётчики; доступно обновление по кнопке и периодическое тихое обновление.

### ТЗ сценария (файл)

1. Откройте выборку **«Сценарии»**.
2. Выделите строку сценария.
3. Нажмите **«ТЗ сценария»** на верхней панели.

В диалоге можно загрузить файл ТЗ с диска, при настроенном на сервере n8n — запустить обработку и скачать исходник или результат. Загрузка и обработка доступны при правах на изменение контента (сценарист, администратор и т.д.); скачивание — при обычном доступе к API.

В таблице сценариев отображаются колонки с именами файлов ТЗ и статусом пайплайна.

## Логи клиента

На Windows журнал пишется в каталог:

`%LOCALAPPDATA%\VKR_MAIN\logs\client.log`

При сбоях сети или API сообщения также попадают в этот файл (и в консоль при запуске из терминала).
