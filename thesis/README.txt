Каталог thesis — черновики текстовой части диплома по проекту VKR_MAIN.

Соглашение:
- Текст в отдельных файлах .txt, кодировка UTF-8, без разметки Markdown (без звёздочек, решёток и т. п.), удобно копировать в Microsoft Word.
- Нумерация файлов: 01_..., 02_... — по мере появления разделов.
- Служебные подсказки (про ссылки, оформление) — в начале соответствующего файла в скобках.

Тема диплома (для согласования с заданием): «Разработка генератора иммерсивного театра» (нейросетевой конвейер в n8n + интеграция в API, настольный и мобильный клиенты).
