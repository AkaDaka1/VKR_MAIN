12. Характеристики и классификация языков программирования.

Язык программирования (ЯП) — формальный язык, с помощью которого человек описывает алгоритмы и структуры данных так, чтобы компьютер мог их выполнить (через компиляцию или интерпретацию).

Характеристики языков программирования
1) Уровень абстракции
- Низкоуровневые: близко к железу (Assembler).
- Высокоуровневые: ближе к человеческим понятиям (Python, Java, C#, JavaScript).
Для ИС чаще применяются высокоуровневые, чтобы быстрее разрабатывать и сопровождать системы.

2) Способ исполнения: компиляция и интерпретация
- Компилируемые: исходный код переводится в машинный код/байткод заранее (C/C++, Go, Rust).
- Интерпретируемые/скриптовые: код выполняется интерпретатором (Python, JavaScript).
- Гибриды: компиляция в байткод + виртуальная машина/JIT (Java, C#).
На практике в ИС важны скорость разработки, экосистема и надежность деплоя, а не только «чистая» производительность.

3) Типизация
- Статическая типизация: типы проверяются до запуска (Java, C#, Go, Rust, TypeScript).
- Динамическая: типы определяются во время выполнения (Python, JavaScript).

Также различают:
- строгая (strong) типизация — меньше неявных преобразований;
- слабая (weak) — больше неявных преобразований (зависит от языка).

Для ИС статическая типизация часто помогает:
- ловить ошибки на этапе сборки;
- проще поддерживать большой код и командную разработку.

4) Управление памятью
- Ручное (C/C++): программист управляет выделением/освобождением.
- Автоматическое (GC): сборщик мусора (Java, C#, JavaScript, Go — частично).
- Подходы с владением/заимствованием (Rust).
В ИС автоматическое управление памятью упрощает разработку и снижает риск утечек/ошибок, но важно следить за производительностью.

5) Поддерживаемые парадигмы
Современные языки часто мультипарадигмальные:
- процедурная/структурная;
- объектно‑ориентированная;
- функциональная;
- логическая (Prolog);
- декларативная (SQL).
В ИС обычно смешивают подходы: бизнес‑логика часто ООП, обработка коллекций — функциональные элементы, запросы — декларативные (SQL).

6) Экосистема и применимость
Для ИС критичны:
- библиотеки для web/API, работы с БД, аутентификации, сериализации;
- фреймворки (Spring, ASP.NET, Django/FastAPI, Node.js);
- инструменты тестирования, CI/CD, контейнеризация.

Классификация языков программирования (основные критерии)
1) По назначению
- общего назначения: C#, Java, Python, JavaScript;
- предметно‑ориентированные (DSL): SQL (запросы к БД), регулярные выражения, язык шаблонов.

2) По парадигме
- процедурные: C, Pascal;
- объектно‑ориентированные: Java, C# (и многие другие);
- функциональные: Haskell, F#, Scala (частично);
- логические: Prolog;
- декларативные: SQL.

3) По уровню
- низкоуровневые: Assembler;
- системные: C/C++, Rust;
- прикладные/высокоуровневые: Python, Java, C#, JS.

4) По типизации
- статические/динамические;
- сильные/слабые;
- явные/неявные (нужно ли явно указывать тип).

5) По способу исполнения
- компилируемые;
- интерпретируемые;
- JIT/VM (байткод).

Примеры выбора ЯП для задач в ИС
- Backend API: Java (Spring), C# (ASP.NET), Python (FastAPI/Django), Node.js (TypeScript).
- Frontend: JavaScript/TypeScript.
- Мобильные клиенты: Kotlin/Swift, кроссплатформенно — Flutter (Dart), React Native (TS/JS).
- Работа с данными и аналитика: Python, SQL.

Итог
Классификация ЯП помогает осознанно выбирать инструменты под задачу ИС: где важны безопасность типов и поддержка больших проектов — статически типизированные; где важна скорость прототипирования — динамические; где важна интеграция и обмен данными — хорошие библиотеки под JSON, БД, сетевые протоколы.
